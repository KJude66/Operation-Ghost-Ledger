# Phase 2 — Hardware Acquisition & Imaging (Weeks 4–5)

**Required deliverable:** Milestone 2 — Acquisition & Chain of Custody Log.

**Acquisition rule:** do not analyse Package B until Package A has been
validated (see [`../02_phase1_public_validation/`](../02_phase1_public_validation/)).

## Tasks

- **Laptop** — create a forensic image of Okafor's Windows 11 laptop using
  a hardware/software write-blocking process.
- **Integrity** — generate and verify SHA-256 hashes for the source/image
  as appropriate and record them.
- **Chain of custody** — record every transfer, handler, date/time,
  purpose, storage location and condition. See
  [`chain_of_custody.csv`](chain_of_custody.csv).
- **Documentation** — record hardware, software/tool versions, procedure,
  timestamps and examiner identity. See
  [`acquisition_log.csv`](acquisition_log.csv).

## Result status

Actual hash values and acquisition timestamps are evidence-dependent and
are intentionally left blank in the logs until generated from the real
Package B files. Never fabricate them.
