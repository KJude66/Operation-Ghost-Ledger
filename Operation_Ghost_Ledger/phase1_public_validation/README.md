**Required deliverable:** Milestone 1 — Public Evidence Validation Report.

**Priority:** validate Package A before examining Package B. Package A has
no formal chain of custody and must establish a defensible baseline.

## Tasks

- **Hashing** — hash every Package A file and catalogue as Exhibits L-01
  through L-05; record source URL and download timestamp. See
  [`hash_catalog.csv`](hash_catalog.csv).
- **Metadata** — extract EXIF/XMP and PDF object metadata and compare
  relevant properties with corresponding Package B versions when available.
- **Audio** — perform spectrogram/structural analysis focused on the 15%
  reference and test for splicing or AI-voice artifacts.
- **PDF** — inspect structure, metadata and embedded objects/JavaScript for
  inconsistencies or manipulation.
- **Spreadsheet** — assess integrity and compare creator/metadata and
  content with any corresponding version found on the seized laptop.
