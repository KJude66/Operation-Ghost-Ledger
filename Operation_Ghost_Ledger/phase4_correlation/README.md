# Phase 4 — Correlation & Reconstruction (Weeks 13–14)

**Required deliverable:** Milestone 3 — Correlation & Reconstruction Report.

## Objective
Correlate Package A and Package B and reconstruct the sequence of events,
testing the [core hypothesis](../01_case_setup/README.md#3-core-hypothesis-and-sub-hypotheses)
against everything found in Phases 1–3.

## Master timeline
Populate [`master_timeline.csv`](master_timeline.csv) using only observed
evidence — it ships with the framework's column headers and a `TBD` /
`[populate from analysis]` scaffold row for each of the five artifact
types the course walkthrough calls out (leaked audio, financial
spreadsheet, AI tool/process, network session, cloud access). Never
fabricate a value.

## Required analysis
1. Correlate independent timestamps.
2. Link filesystem, memory, network, mobile and cloud artifacts.
3. Test competing hypotheses.
4. Identify authentic, manipulated and inconclusive components.
5. State limitations and confidence.
6. Avoid legal conclusions such as “guilty” or “innocent.”
